# UW Data Developer Interview
Coding challenge for the uw data developer interview.

# How To Run the Script
Make sure requirements are satisfied.

## Requirments
```
python >= 3.12 (can't guarentee this will work for older versions)
uv (recommended) or pip
```

Clone the repo:
```
git-clone https://github.com/jgage930/uw-coding-challenge.git
```

cd into directory
```
cd uw-coding-challenge
```

## Running With uv (Recommended)
To run with uv simply run:
```
uv run python -m app
```

## With pip
Create a virtual enviroment and activate
```
python -m venv venv
source venv/bin/activate
```

install packages with
```
pip install -r requirements.txt
```

Finally execute the script:
```
python -m app
```
